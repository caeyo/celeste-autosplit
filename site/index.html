Using the auto splitter

LiveSplit automatically downloads and manages this auto splitter - do not manually install it yourself.

Other livesplit-core apps, such as LiveSplit One, should read the global auto splitter list and install it for you as well. If you need to manually install it, download celeste_autosplit.wasm and activate it via whatever means the app uses.
