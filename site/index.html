Celeste Auto Splitter Settings

Edit the auto splitter's settings in your splits file. The file stays in your browser and is never uploaded.

Close your splits in your LiveSplit host first, or the host overwrites the edit when it saves.

These splits have settings from the old LiveSplit.Celeste component. Importing converts them to this auto splitter's settings, the same way the LiveSplit component does. It loads about 2 MB once, and then runs in your browser.

Segments

Getting the auto splitter

LiveSplit, and livesplit-core hosts that read the auto splitter list, install it for you. For the others, download celeste_autosplit.wasm, then:

  1. AlexKnauth's livesplit-one-druid: choose the file in its auto splitter settings.
  2. CryZe's older desktop and Druid apps: put the path to the file in their config file.

CryZe's newer desktop app reads the list.
